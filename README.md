## MCP Servers & Zen Mode Workflow

> Press the command palette hotkey inside the TUI to switch model providers, inspect active MCP tools, or toggle distraction-free Zen mode.

- Native terminal diff viewer with keyboard-only navigation.
- Unified provider catalog supporting cloud APIs and local Ollama endpoints.
- Session history persisted per workspace directory.
